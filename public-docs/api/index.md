# API Reference

Generated from the XML doc comments on `uCodeFirst`'s public types. Browse by namespace in the sidebar:

- **`uCodeFirst.Attributes`** — `[DocumentType]`, `[ElementType]`, `[MediaType]`, `[CompositionType]`, and the other structural attributes.
- **`uCodeFirst.DataTypes`** — property-editor attributes (`[TextString]`, `[RichText]`, `[BlockList]`, …) and their base classes.
- **`uCodeFirst.BuiltIn`** — stub classes for Umbraco's built-in media types (File, Image, Video, …).

See [Getting Started](../docs/getting-started.md) for how these fit together.
